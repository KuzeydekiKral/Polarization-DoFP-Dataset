# Polarimetric DoFP Mosaic Dataset for Target Tracking Applications under High Occlusion

This repository provides the **Polarimetric DoFP Mosaic Dataset**, created for research on **object tracking and detection in polarization (DoFP)  imaging** under **high occlusion conditions**.

The dataset consists of polarization mosaics captured using a Division of Focal Plane (DoFP) polarimetric camera. It is designed to support the development and evaluation of polarization-based visual tracking algorithms.

## 🧩 Dataset Description

Each video sequence in the dataset includes:
- **DoFP mosaic images** in `.tiff` format  
- Various **occlusion levels** and **illumination conditions**

**Target types:** vehicles 

---

## 🧠 Applications

This dataset is intended for:
- Polarization-based **object tracking**
- **Target detection** under partial or full occlusion
- Evaluation of **polarization feature descriptors**
